# A000638

> Number of permutation groups of degree n; also number of conjugacy classes of subgroups of symmetric group S_n; also number of molecular species of degree n.
> — [OEIS A000638](https://oeis.org/A000638)

Offset 0: 1, 1, 2, 4, 11, 19, 56, 96, 296, 554, 1593, 3094, 10723, 20832, …

There is no formula; the known terms come from computer algebra systems
that list the conjugacy classes of subgroups of S_n. A short program has to
build the subgroups itself, so it gets a handful of terms.

### Python 3 — 282 bytes

```python
from itertools import*
n=0;D=[]
while S:=[*permutations(range(n))]:
 for K in(L:=[{S[0]}]):
  for g in S:
   J=K|{g}
   while J<(J:={tuple(a[i]for i in b)for a in J for b in J}):0
   if J not in D:D+=[{tuple(s.index(p[x])for x in s)for p in J}for s in S];L+=J,
 print(len(L)-1);n+=1
```

**How it works**

- Permutations of range(n) are tuples, a subgroup is the set of its
  elements, and `tuple(a[i]for i in b)` is the product a∘b.
- **Closure.** J starts as K ∪ {g}, which contains the identity, and is
  replaced by J·J until it stops growing. The result is the subgroup
  generated by K and g.
- **Search.** `L` is a list of class representatives; the `for` loop also
  visits the ones appended while it runs. Every subgroup H ≠ 1 is ⟨K, g⟩ for
  a proper subgroup K (for instance K maximal in H) and some g. If K is
  conjugate to a listed K′, say K = σK′σ⁻¹, then σ⁻¹Hσ = ⟨K′, σ⁻¹gσ⟩, so
  trying every g ∈ S_n on every listed representative reaches a conjugate
  of every subgroup.
- **Conjugacy.** When a closure is not in `D`, the program appends it to
  `L` and puts all its conjugates s⁻¹Js into `D`
  (`tuple(s.index(p[x])for x in s)` is s⁻¹ps). So `L` gets one subgroup per
  conjugacy class, plus the trivial group twice: it starts there and is
  found again from K = 1, g = 1. Hence `len(L)-1`.
- `D` is never cleared: subgroups of smaller degree hold shorter tuples and
  never equal a new one.

**Notes**

- Exhaustive search, right for every n, only slow: a(0) … a(4) print in a
  second, a(5) takes about 45 s on this PC (2280 closures of up to 120
  elements, squared), and a(6) would need tens of thousands of closures in
  S₆. The bar is 6 terms in 120 s.
- [A000637](../A000637/) uses the same search.
