**What is counted**

- The OEIS comment: a(n) is the number of self-complementary equivalence
  classes under the group B_n generated by the permutations and the
  negations of the n inputs, that is, classes that contain the complement
  ¬f of their functions.
- Complementing maps B_n-orbits to B_n-orbits. By de Bruijn's lemma (for H
  normal in G and σ in G, (1/|H|) Σ_{h∈H} fix(hσ) is the number of H-orbits
  that σ maps to themselves), with H = B_n and σ = complement,
  a(n) = Σ_g #{f : f∘g = ¬f} / |B_n|.
- f∘g = ¬f forces f to alternate along each cycle of g on the 2ⁿ points, so
  it has 2^c(g) solutions if every cycle has even length and none otherwise.
  For an affine map over GF(2), an odd cycle exists exactly when there is a
  fixed point (the XOR of the points of an odd cycle is fixed; see
  [A000370](../A000370/)), and g has a fixed point exactly when all its
  signed cycles are positive. So a(n) = Σ 2^c(g) / |B_n| over the g with at
  least one negative signed cycle.

**How it works**

- This is the [A000616](../A000616/) recursion over signed cycle types (see
  that page for the fixed-point count of gᵗ and the exact floors), with one
  extra factor at the leaf: negative cycles are stored as positive lengths
  and positive ones as negative lengths, which add up to −n when all cycles
  are positive. So `sum(L)+n` is 0 exactly when g has a fixed point, and
  `sum(L)+n and …` drops those elements.
- The integer f(r,L) is the number of B_r-orbits that τ composed with
  complementing maps to themselves, by the same lemma, so `//r>>1` is exact.
- Because a leaf can be 0, the recursion branch comes first: `r and … or …`
  returns the leaf only at r = 0 (every f(r,L) with r ≥ 1 is positive).

**Notes**

- a(n) = 2·[A000370](../A000370/)(n) − A000616(n).
