# A000679

> Number of groups of order 2^n.
> — [OEIS A000679](https://oeis.org/A000679)

Offset 0: 1, 1, 2, 5, 14, 51, 267, 2328, 56092, 10494213, 49487367289

Only eleven terms are known; the last ones took the specialised p-group
algorithms of Besche, Eick, O'Brien and others. A short exhaustive program
gets the groups up to order 16.

### Python 3 — 473 bytes

```python
from itertools import*
c=lambda G,d=0:min([(*r,)for T in product(*[G[0]]*d)if[L:=[0]]if(r:=[L.index(y)for x in L for g in T if(y:=G[x][g])in L or[L.append(y)]])if L[len(G)-1:]]or[c(G,d+1)])
Q={0:[[0]]}
while[print(len(Q))]:Q={c(G:=[[2*t[t[x][(R,A)[e][k]]][h*e*j]+e^j for k in R for j in(0,1)]for x in R for e in(0,1)]):G for t in Q.values()for R in[t[0]]for A in permutations(R)for h in R if all(A[t[a][b]]==t[A[a]][A[b]]and t[A[A[b]]][A[h]]==t[h][b]for a in R for b in R)}
```

**How it works**

Groups are multiplication tables on 0 … N − 1 with identity 0; the
identity row `t[0]` is also the list of elements. `Q` maps a canonical
form to one table per isomorphism class of order 2ⁿ, starting from the
trivial group.

- **Extensions.** A group G of order 2N (N a power of 2) has a subgroup H
  of index 2, which is normal. Pick x ∈ G \ H; conjugation h ↦ xhx⁻¹ is an
  automorphism α of H, h₀ = x² lies in H, and α(h₀) = h₀,
  α²(h) = h₀hh₀⁻¹. Conversely any α ∈ Aut(H) and h₀ ∈ H with these two
  properties give a group on the pairs h·xᵉ:
  (h₁xᵃ)(h₂xᵇ) = h₁·αᵃ(h₂)·(h₀ if a = b = 1)·x^(a+b mod 2).
  Every group of order 2N arises this way from the representative of the
  class of H, so trying all of them on every representative of order N
  yields every class of order 2N.
- **The test.** `A` runs over all permutations; `A[t[a][b]]==t[A[a]][A[b]]`
  for all a, b makes it an automorphism. `t[A[A[b]]][A[h]]==t[h][b]` for all
  b says α²(b)·α(h₀) = h₀·b: at b = 0 it gives α(h₀) = h₀, and then it is
  the condition on α². (R,A)[e] is α^e, and element h·xᵉ gets index
  2h + e; `2*…+e^j` adds the bit e xor j, because 2m + e has low bit e.
- **Isomorphism.** For a tuple T of elements, a breadth-first walk from the
  identity by right multiplication with the members of T numbers the
  elements in the order found, and r lists the numbers of x·g for every
  element x in that order and every g in T. When T generates G, r is the
  Cayley graph with labelled generators; it fixes the permutation group
  generated by right multiplications, which is isomorphic to G. So two
  groups are isomorphic exactly when they share an r for some generating
  d-tuples. `c` takes the least r over all generating d-tuples, d being the
  least size of a generating tuple (it tries d = 0, 1, 2, … and stops at the
  first d with one): an isomorphism invariant that tells the classes apart.
  `L[len(G)-1:]` is non-empty exactly when T reached every element.

**Notes**

- Exhaustive search with exact integer work, so the program is right for
  every n; only the time grows. Orders 1 … 16 (a(0) … a(4)) print in about
  9 s on this PC: 184 tables of order 16 are built from the five groups of
  order 8. Order 32 would need the automorphisms of groups of order 16 from
  all 16! permutations, so a(5) never comes. The bar is 5 terms in 60 s.
