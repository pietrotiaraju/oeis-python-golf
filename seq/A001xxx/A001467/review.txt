2b5e65ab320c Definition from the entry's PARI program and example (the title only says 'an expansion'): x = pi; d = 1 while x >= 1, else d = nearest integer to 1/x; print d, x -= 1/d; all 9 b-file terms agree. Since 3 < pi < 4 the first three d are 1 and then x = pi-3 is in (0,1); afterwards |x - 1/d| < |x|/2, so |x| < 1 forever and d is always round(1/x): the program prints the three 1's and starts at pi-3. Exact pi bounds come from Gibbons' spigot state f(X) = (qX+y-4q)/t with the series tail X strictly in (3,4), as in A000796, so x is strictly between (y-q)/t and y/t. A candidate c is accepted only if h = x^2 - 4(1-cx)^2 >= 0 at both ends; h is concave for c != 0 (c = 0 can never pass), so h(x) > 0 and |1/x - c| < 1/2 at the true x. Pi is irrational, so 1/x is never a half-integer and every step is eventually decided. Exact integers; right for every n.
