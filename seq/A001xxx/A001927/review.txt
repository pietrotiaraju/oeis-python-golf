# it computes the sequence for every n. This file changes only through pull requests.
1022a2ef4666 Counts connected posets on n labeled points. Every reflexive relation is listed as bit rows (row i = up-set of i, ranging over the masks containing bit i). For each, the program counts the sets s for which every row a has a&s in {0,a} and every row is transitive; this is 0 for a non-transitive relation and 2^c (c = components of the comparability graph) for a quasi-order. The count is shifted left by n minus the number of distinct rows: rows of a quasi-order are equal iff i<=j<=i, so the shift is 0 exactly for posets and makes the count >= 4 for every other quasi-order. 0<count<3 then keeps exactly the connected posets (and the empty one at n=0, a(0)=1). Exhaustive search with exact integers, right for every n.
