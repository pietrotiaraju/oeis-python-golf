f2fd93dc39a4 a(n) = h(-p) for p = A001986(n) (class number of Q(sqrt(-p)), as the entry's comment says; h(-4p) = 3h(-p) would give 3 for p = 19). The search is the A001986 program (Wilson's theorem for odd primes, Euler's criterion, exact trial division up to r/q). The class number is counted exactly as the number of reduced forms (|b| <= a <= c, b >= 0 on the boundary); the page shows that for these prime discriminants every form is primitive and the boundary cases a = c, |b| = a cannot occur (except (1,1) for -p, taken as b = -1), so the pairs (a,b) with b of the right parity in [-a,a), a | (b^2+|D|)/4 and a^2 <= (b^2+|D|)/4, with 3a^2 <= |D|, are exactly the reduced forms.
