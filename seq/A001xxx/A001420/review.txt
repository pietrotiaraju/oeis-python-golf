37f9fad17b30 Redelmeier's algorithm on the triangular tiling, no stored terms. Triangle x of row y is c = x + K*y with K = 2n+1 odd; its neighbours are c+-1 and c+K (c even) or c-K (c odd), i.e. the honeycomb dual of the tiling. Translations keep each triangle's orientation and move c by an even amount, so every fixed polyiamond has exactly one translate whose least cell (lowest row, then leftmost) is 0 or 1; U=[1,0] starts the search from both (0 popped first, so animals containing 0 are counted from 0, the rest from 1). S is pre-seeded with all codes -2K..1 (cells below or left of the start), so only cells after the start are ever offered; K > n guarantees no two cells within reach share a code (the page gives the argument). Standard Redelmeier untried-set recursion, so each fixed polyiamond is counted exactly once. Matches all required terms; correct for every n, only time-limited.
