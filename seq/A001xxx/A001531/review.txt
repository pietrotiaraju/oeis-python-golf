b81896ba6926 The OEIS data counts self-dual functions of n+1 variables (a(2)=3: x, maj, parity of 3 inputs; checked element by element for n<=5) up to permuting/negating inputs (B_{n+1}; output negation adds nothing for self-dual f). Burnside: g fixes 2^(P/2) self-dual functions when complementation maps no cycle of g to itself, else 0 (P = number of cycles, the A000370 gcd sum). A cycle is self-mapped iff c*g^t has a fixed point for some t; per signed cycle this is a parity of (t*[negative]+l)/gcd(t,l), i.e. a 2-adic condition, and the page shows t = max(1, negative cycle lengths) is the only candidate needed. Recursion over signed cycle types as A000370; floors exact by de Bruijn's lemma on the self-dual functions, and f(r,L)>0 for r>=1 so the and/or never falls through. Exact integers, every n.
