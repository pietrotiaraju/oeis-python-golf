321a9bdaadcd Counts connected quasi-orders (= connected finite topologies, open sets = up-sets) on n labeled points. Every reflexive relation is listed as bit rows (row i ranges over the masks containing bit i). For each, the program counts the sets s for which every row a has a&s in {0,a} and every row is transitive (j in a implies row j inside a). The transitivity part does not depend on s, so the count is 0 for a non-transitive relation; for a quasi-order it is the number of clopen sets, 2^c with c components, since s is open and closed iff every row lies inside or outside s. 0<count<3 keeps exactly the connected ones (and the empty space at n=0, a(0)=1). Exhaustive search with exact integers, right for every n.
