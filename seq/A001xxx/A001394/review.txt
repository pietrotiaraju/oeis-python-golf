e2a09b32a8b3 Counts n-step self-avoiding walks on the diamond lattice by exhaustive depth-first search. Sites are coded through lattice coordinates over b1=(0,2,2), b2=(2,0,2), b3=(2,2,0): an even site a gets (B+1)a1+2a2+(B^2+1)a3, an odd site c gets the bitwise complement of that, so from either sublattice the four neighbours of code p are ~p, 1-p, B-p, B*B-p. With B=2n+1 odd the code is injective on every n-step walk (all step codes are even, so the sublattices never share a code; inside a sublattice the base-B digits a1+2a2+a3, a1, a3 vary by less than B), so S is an exact visited set and the count is exact for every n; no theorem beyond this, argued on the page.
