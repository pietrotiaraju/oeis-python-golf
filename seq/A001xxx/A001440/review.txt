87482d8e8a3f Exhaustive search, no stored terms. Dots are coded K*x+y with K=2n, so a code difference determines the displacement vector; the partial array has distinct vectors iff the difference set (zero included) has k(k-1)+1 elements. The search builds every involution once (smallest unassigned column paired with itself or a later one), so it counts S(n) = symmetric Costas arrays exactly. The class count a(n) = S(n)/2 for n >= 3 is proved on the page: no Costas array of order >= 3 is fixed by the half-turn (columns 0,1 and n-2,n-1 would repeat a vector), so a symmetric array has stabiliser {1, transpose} and its 4-element class holds exactly 2 arrays symmetric about the main diagonal; ceil(S/2) also gives a(1)=a(2)=1. Matches all 16 required terms (and Drakakis 2011, two symmetric arrays per class); correct for every n, only time-limited.
