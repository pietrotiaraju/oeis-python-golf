500406a36bd1 Exact exhaustive search over all placements of n queens on n^2 squares (each set of n squares tried once, in increasing order). L[i] is the bit mask of squares attacked or occupied by a queen on i (row, column or diagonal difference zero; blocking is irrelevant since the nearest queen on a line attacks). g(i,a,m) prunes only when the free count N-|a| is already <= t, which is valid because adding queens never frees a square, so g(0,0,n) is True exactly when some placement leaves more than t squares free; t rises from 0 while that holds, so the printed t is the maximum a(n). No theorem needed; correct for every n (the OEIS terms from n=19 are only probable, but the bar is 9 terms).
