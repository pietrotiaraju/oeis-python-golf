e82eeab5ddde Counts Hamiltonian cycles of the 2n x 2n knight's graph by exhaustive DFS for every n. From side 4 on the corner 0 has exactly the two neighbours 1+2i and 2+i, so every closed tour contains them as a-0-b; the program counts walks a -> ... -> b -> 0 through every square once, exactly one per undirected tour (no halving). g(p,S) keeps S = unvisited squares + head + 0; success is S == {0}; entering 0 early cannot complete (shown on the page). The only pruning drops a branch when some unvisited square other than 0 has fewer than two neighbours left in S, a necessary condition for any completion, so the count is exact. 2x2 has no knight moves (prints 0 via +False).
