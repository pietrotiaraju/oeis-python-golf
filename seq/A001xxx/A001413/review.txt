fa0ab1c57f0d Definition (OEIS comments): a(n) is the number of closed self-avoiding walks of 2n steps on the simple cubic lattice that start and end at the origin, distinct step sequences counted separately (a(n)=4n*A001409(n), a(1)=0). The program is an exhaustive depth-first search: the visited set starts as {.5} (a placeholder, so the origin itself is not marked visited), every step goes to an unvisited neighbour p+-1, p+-B, p+-B^2, and after 2n steps the walk scores 1 iff it stands at the origin; hence it counts exactly the walks p0=0,p1,...,p2n=0 with p1..p2n distinct. For n=1 these are the six out-and-back walks, which are not cycles; the test p==0<B^2 (B XOR 2 is 0 only for B=2) scores 0 there, and for n>=2 p1!=p(2n-1) so every such walk is a genuine 2n-cycle. Codes x+yB+zB^2 with B=2n are exact: a nonzero vector with code 0 has |x|+|y|+|z|>=B+1=2n+1, more than any two points of a 2n-step walk are apart. Exact integer arithmetic, no truncation: correct for every n (only time-limited).
