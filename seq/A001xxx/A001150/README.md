# A001150

> Number of n-input 2-output switching networks with GL(n,2) acting on the input and S(2) and C(2,2) acting on the output.
> — [OEIS A001150](https://oeis.org/A001150)

Offset 1: 3, 13, 146, 40422, 232328410830, 2110021709419835241732893678, …

### Python 3 — 219 bytes

```python
n=1
while 1:
 t=k=0
 for i in range(1<<n*n):
  for _ in[m:=[0]]*n:m+=[y^i%2**n for y in m];i>>=n;s=r=len({*m})>>n;k+=8*r
  for x in m:
   while~x:m[x],x=-1,m[x];i^=1;r<<=x<0
   s<<=i;i=0
  t+=r*(r+s+s)
 print(t//k);n+=1
```

**How it works**

- What it counts: maps f: {0,1}ⁿ → {0,1}² (n-input, 2-output switching
  functions) up to f ↦ h∘f∘A, with A ∈ GL(n,2) (invertible linear
  substitutions of the inputs) and h in the group of order 8 generated by
  swapping the two outputs (S(2)) and complementing either of them
  (C(2,2)). On the four output values 00, 01, 11, 10 this is the symmetry
  group of a square.
- Burnside over the pairs (A, h): (A, h) fixes f when f(Ax) = h(f(x)) for
  every x. On a cycle of x ↦ Ax of length L, f is determined by its value y at
  one point, and going round the cycle forces h^L(y) = y. So the pair fixes
  Π F_h(L) maps, the product over the cycles of A on the N = 2ⁿ input
  vectors, where F_h(L) = #{y : h^L(y) = y} is the sum of the lengths of
  the cycles of h that divide L. Only the cycle lengths of A matter, and
  F_h only through the conjugacy class of h:

  | h ∈ S(2) × C(2,2) | count | cycles on {0,1}² | F_h(L) |
  |---|---|---|---|
  | identity | 1 | 1 1 1 1 | 4 |
  | complement one or both outputs | 3 | 2 2 | 4·[2∣L] |
  | swap, swap and complement both | 2 | 1 1 2 | 2 + 2·[2∣L] = 2^(1+[2∣L]) |
  | swap and complement one | 2 | 4 | 4·[4∣L] |

  A linear map fixes the zero vector, a cycle of length 1, so the classes
  with F_h(1) = 0 (rows 2 and 4) fix nothing. With c cycles of A, e₂ of
  them of even length:
  a(n) = Σ_A (4^c + 2·2^(c+e₂)) / (8·|GL(n,2)|).
- The loop is the one of [A000832](../../A000xxx/A000832/) (output swap
  only, Σ_A (4^c + 2^(c+e₂)) / (2·|GL(n,2)|)) with the two new weights:
  `k+=8*r` and `t+=r*(r+s+s)`. `i` runs over all 2^(n²) n×n matrices over
  F₂; its n-bit digits are the columns, and `for _ in[m:=[0]]*n:` resets
  `m` to [0] and doubles it n times with `m+=[y^col for y in m]`, so that
  `m[x]` ends as Ax. After each column `len({*m})>>n` is computed: 0 until
  the last column, then 1 exactly when A is invertible. `s` and `r` start
  at that flag, and `k` counts 8·|GL(n,2)|.
- The walk `while~x:m[x],x=-1,m[x]` marks visited points −1, and `r<<=x<0`
  doubles `r` when a cycle closes, so `r` ends at 2^c. After the column
  loop `i` is 0, so it serves as the step counter: `i^=1` at each step
  leaves i = (L+1) mod 2 after a cycle of length L, 1 exactly when L is
  even, so `s<<=i` makes s = 2^e₂; `i=0` resets it, and a start point
  inside a finished cycle takes no step.
- `t+=r*(r+s+s)` adds 4^c + 2·2^(c+e₂), and 0 for a singular matrix.

**Notes**

- The loop visits all 2^(n²) matrices: a(1)–a(4) print in about 1.3 s
  here, and a(5) would need 2²⁵ matrices on 32 points (around 20 minutes).
  The bar is these 4 terms in 60 s, as for the other GL(n,2) tables; the
  b-file is the OEIS data, 7 terms.
- Exact integer arithmetic; correctness rests only on Burnside's lemma. The
  class table was checked against the eight maps of the output group, and
  an explicit orbit count (all 4^(2ⁿ) maps under every pair (A, h)) gives
  3, 13, 146 for n = 1, 2, 3.
- Starting `s` at 2 instead (so that `t+=r*(r+s)` stays) costs more than
  the 2 bytes of `+s`: the flag is shared by `r` and `s`, and starting the
  matrix loop at 2^(n²) to leave i = 1 for the first cycle (always the
  fixed zero vector) costs 7.
- The other range groups with GL(n,2) on the inputs (m = 2/3 outputs):
  trivial [A000817](../../A000xxx/A000817/)/[A000818](../../A000xxx/A000818/),
  S(m) [A000832](../../A000xxx/A000832/)/[A000833](../../A000xxx/A000833/),
  C(2,m) [A000847](../../A000xxx/A000847/)/[A000848](../../A000xxx/A000848/),
  GL(m,2) [A000877](../../A000xxx/A000877/)/[A000878](../../A000xxx/A000878/),
  AG(m,2) [A000892](../../A000xxx/A000892/)/[A000893](../../A000xxx/A000893/).
