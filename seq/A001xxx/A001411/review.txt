ed640f359c08 Definition: a(n) is the number of n-step self-avoiding walks on the square lattice starting at the origin. The program is an exhaustive depth-first search over all such walks: f(p,S) extends the walk from p through the unvisited neighbours p+-1, p+-B and scores 1 when the walk has n+1 points. Points (x,y) are coded x+yB with B=n+1; two points of an n-step walk satisfy |dx|+|dy|<=n<B, and x+yB=x'+y'B with y!=y' would need |dx|>=B, so the code is one-to-one on every walk and the visited set S is exact. Every walk is generated exactly once, the count is exact integer arithmetic, and nothing is truncated or conjectured, so the output is a(n) for every n (only time-limited; recursion depth about 2n).
