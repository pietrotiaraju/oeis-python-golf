5fb210d13bb3 Commutative semigroups up to isomorphism. Orderly exhaustive search: the multiplication table is filled cell by cell (row-major); unknown cells are the sentinel N = n*n with enough padding that any product involving an unknown reads N. A prefix is cut if an associativity triple (ab)c vs a(bc), or a commutativity pair ab vs ba, is fully known and differs, or if for some relabelling the image table, read in the same order, is already smaller at the first cell where they differ (determined cells only; unknown reads as n, larger than every symbol), so no completion is lexicographically minimal; on full tables this is the exact minimality test. Exactly one table per isomorphism class is counted (for commutative tables reversal is the identity, so isomorphism is the right equivalence). No theorem needed; correct for every n.
