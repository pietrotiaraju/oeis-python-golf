# A001390

> Smallest multiplicative generator for quadratic residues mod prime(n).
> — [OEIS A001390](https://oeis.org/A001390)

Offset 1: 1, 1, 4, 2, 3, 4, 2, 4, 2, 4, 7, 3, 2, 9, 2, 4, 3, 4, 4, 2, 6, 2, …

### Python 3 — 109 bytes

```python
P=p=1
while[-P%p==1==print(next(g for g in range(1,p)if len({pow(g,j,p)for j in range(p)})==p//2))]:P*=p;p+=1
```

**How it works**

- **What is generated.** The nonzero quadratic residues mod a prime p
  form the subgroup of squares of the cyclic group (ℤ/p)\*, of order
  (p − 1)/2, and it is the only subgroup of that order. An element g
  generates it exactly when its powers g⁰, g¹, … are (p − 1)/2 distinct
  residues: the powers of g form the subgroup ⟨g⟩, which has ord(g)
  elements, and a subgroup of order (p − 1)/2 must be the squares. So a(n)
  is the least g ≥ 1 with |{g^j mod p}| = (p − 1)/2 = `p//2`. The subgroup
  is cyclic, so such a g exists below p and the search stops.
- **p = 2 and 3.** Here the residues are just {1}, generated by 1, which
  is what the entry gives; `p//2` = 1 and g = 1 has the one power 1, so
  the same test returns 1 for both.
- **The powers.** `{pow(g,j,p)for j in range(p)}` takes j = 0 … p − 1,
  more than a full period of g, so the set is all of ⟨g⟩.
- **Primes** by Wilson's theorem, as in [A000040](../../A000xxx/A000040/):
  with P = (p − 1)!, p > 1 is prime if and only if `-P%p==1`, and the chain
  `-P%p==1==print(…)` only calls `print` (and runs the search) for primes.
  `next(…)` stops at the first g that works.

**Notes**

- Exact integer arithmetic, correct for every n; it rests on Wilson's
  theorem and on the group (ℤ/p)\* being cyclic.
- Each candidate g costs p modular powers, and P = (p − 1)! grows to
  about p·log₁₀ p digits, so the program slows down roughly
  quadratically. The b-file has 10000 terms (up to p = 104729); the bar is
  1200 terms (p = 9733) in 60 s.
