Mathar's comment on the entry: the distinct values (= records) of m(r) = r + A000232(r), where A000232(r) is the column of the first entry > 2 in row r of Gilbreath's triangle (row 0 = primes, row r+1 = absolute differences of row r); m is nondecreasing because c(r+1) >= c(r)-1 (proved on the page). A separate numpy check over all 98842358 primes below 2013265920 matches all 83 b-file terms. The program sieves the primes below N (Eratosthenes), builds the rows by exact absolute differences and reads the first column > 2 of each row; every computed entry is exact, a row without such an entry stops the pass (later rows need more primes since m only grows), N doubles and the pass restarts, printing only values above the last one. Exact for every n, no conjecture (if a row never had an entry > 2 the sequence would end and the program would print nothing more), no stored terms.
