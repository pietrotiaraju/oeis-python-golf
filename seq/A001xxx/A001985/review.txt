989351b8e187 a(n) = h(-p) for p = A002223(n), the least prime p = 7 (mod 8) such that the first n primes are quadratic residues mod p (class number of Q(sqrt(-p)), as the entry's comment says). Primes p_n by Wilson's theorem; for a prime r > q all d <= q are residues iff all primes <= q are, tested by Euler's criterion pow(d,(r-1)/2,r) <= 1 for d = 0..q (a prime r <= q fails). Trial division up to r/q is exact: a candidate passing the Euler test has no prime factor p <= q (it would force r = p^j, and then the base p-1, of order 2p mod p^2, fails). The class number is counted exactly as the number of reduced forms (|b| <= a <= c, b >= 0 on the boundary); the page shows that for these prime discriminants every form is primitive and the boundary cases a = c, |b| = a cannot occur (except (1,1) for -p, taken as b = -1), so the pairs (a,b) with b of the right parity in [-a,a), a | (b^2+|D|)/4 and a^2 <= (b^2+|D|)/4, with 3a^2 <= |D|, are exactly the reduced forms.
