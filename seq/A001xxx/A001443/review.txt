80ea02faca2f Exhaustive backtracking, no stored terms. A strong starter in Z_v (v=2n+1) is a partition of the nonzero elements into n pairs {x,y} whose differences +-(y-x) cover every nonzero element once and whose sums x+y are distinct and nonzero. The search always pairs the smallest unpaired x with a larger unpaired y, so each starter is built exactly once; set E holds the used differences d=y-x and v-d plus the used sums coded as (x+y)%-v (in -v+1..-1 for nonzero sums, 0 for the forbidden sum 0), so sums and differences never collide in one set and E={0} at the start forbids sum 0. A pair is accepted iff neither its difference nor its sum code is in E. Matches all 11 required terms; correct for every n, only time-limited.
