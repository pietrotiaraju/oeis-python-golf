5f7a985aa3d4 a(n) = H_n(2,n), the n-th hyperoperator with base 2 (A054871 convention). The program evaluates the definition: closed forms y+1, y+2, 2y for H_0, H_1, H_2 (what the recursion gives from the successor with bases 2 and 0, by induction on y), and for n >= 3 the defining recursion H_n(2,0) = 1, H_n(2,y) = H_(n-1)(2, H_n(2,y-1)), so it is right for every n with no stored terms. The page shows the and/or short-circuits are safe (True from y<1 is only passed on as an argument; the closed form is 0 only for H(2,0), never called). Only a(0..4) = 1, 3, 4, 8, 65536 exist in practice: a(5) needs H_4(2,65536), a tower of 65536 twos, and the program stops there on Python's recursion limit (an interpreter limit). The bar is the five terms of the b-file.
