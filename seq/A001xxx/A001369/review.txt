d2b42acfa404 Definition (as the entry's PARI program and data read the title): write 1, 2, ..., 9, 10 over and over, giving the periodic digit string 12345678910 12345678910 ..., and cut it into consecutive blocks of lengths 1, 2, 3, ...; a(n) is block n read as a number (leading zeros dropped). The literal '12345678910' is that definition (the numbers 1 to 10 written out), not stored terms; it is flagged only because its first ten digits are also a(1)-a(4). The program repeats it n^2 times (11n^2 > n(n+1)/2 digits, enough for every n), slices block n at offset t = n(n-1)/2 and prints int() of it, so it is exact for every n; no theorem needed. Only limit: int-to-str at 4300 digits (n > 4300), an interpreter limit.
