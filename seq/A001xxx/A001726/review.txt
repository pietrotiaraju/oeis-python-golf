b042af0bb3c3 Finite sequence (keyword fini,full): the weight distribution of the second-order Reed-Muller code RM(2,6), a(n) = number of codewords of weight 4n. The program prints a stored list; every value is the Sloane-Berlekamp theorem for RM(2,m) at m=6 (MacWilliams-Sloane ch. 15): A(32+-16) = 2604, A(32+-8) = 291648, A(32+-4) = 888832, A(0) = A(64) = 1, and A(32) = 2^22 - 2 - 2*(2604+291648+888832) = 1828134; the list is symmetric because the all-ones word is in the code. The page derives each number from the formula, and a Gray-code enumeration of all 2^22 codewords gives the same counts.
