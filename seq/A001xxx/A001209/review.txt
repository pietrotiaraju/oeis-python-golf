# Programs read and approved: the first 12 hex digits of the SHA-256 of the program, then why
# it computes the sequence for every n. This file changes only through pull requests.
ce77851783b4 Exhaustive search, no stored terms. a(n) = n(n,4): the largest N such that some set of 4 stamp values pays every amount 1..N with at most n stamps (the OEIS data, per Lunnon's comment). f keeps, for the current set, bitmasks L[j] of the amounts payable with at most j stamps, adds a stamp a by L'[j] = L[j] | L'[j-1]<<a, and tries every next stamp from the last one up to range+1. A larger stamp leaves range+1 unpaid, so it can be replaced by range+1, range+2, ... without loss: some optimal set is visited. Repeats and 0 only give sets with fewer stamps, whose range is still at most n(n,4). The answer is the largest range at depth 4, exact for every n; no theorem or conjecture is used.
