# A001381

> Weight distribution of binary [ 48,24,12 ] quadratic residue code.
> — [OEIS A001381](https://oeis.org/A001381)

Offset 0: 1, 0, 0, 17296, 535095, 3995376, 7681680, 3995376, 535095, 17296, 0, 0, 1

### Python 3 — 140 bytes

```python
c=[0]
exec('c+=[x^9205487*len(c)for x in c];'*12)
w=[-~(x^y<<12).bit_count()//2for x in c for y in c]
for k in range(13):print(w.count(2*k))
```

**How it works**

- **The code.** 47 is a prime ≡ −1 (mod 8), so 2 is a quadratic residue
  mod 47; it has order 23, so its powers are exactly the 23 residues. Over
  GF(2), x⁴⁷ − 1 therefore splits as (x + 1)·g(x)·g\*(x) with two
  irreducible factors of degree 23: g(x) = ∏(x − αʳ) over the residues r,
  and its reciprocal (roots α⁻ʳ, the non-residues). The cyclic code
  generated by either is the binary quadratic-residue code [47, 24, 11]
  (the two are equivalent under i ↦ −i), and the overall parity bit
  extends it to the [48, 24, 12] code of the OEIS name. Here
  g(x) = x²³ + x¹⁹ + x¹⁸ + x¹⁴ + x¹³ + x¹² + x¹⁰ + x⁹ + x⁷ + x⁶ + x⁵ + x³ +
  x² + x + 1, the bit mask 9205487: it divides x⁴⁷ − 1 and has degree 23,
  and by the splitting above that already makes it one of the two QR
  generators.
- **A basis in two halves.** The words g(x)·xⁱ, i = 0…23, have degrees up
  to 46 < 47 (no wrap-around) and are independent, so they span the 2²⁴
  codewords. `c` is the span of the first twelve, 4096 words: `exec` runs
  `c+=[x^9205487*len(c)for x in c]` 12 times, and before the i-th run the
  list has 2ⁱ words, so `9205487*len(c)` is g(x)·xⁱ. The last twelve are the first twelve moved up 12 places, so
  every codeword is `x^y<<12` (x ^ (y << 12)) for exactly one pair x, y in
  `c`: the 2²⁴ pairs list each codeword once.
- **Weights.** `(x^y<<12).bit_count()` is the weight w of the length-47
  word; the parity bit makes it w + (w mod 2) = 2⌊(w + 1)/2⌋ in the
  extended code, so the list holds half the extended weight, `-~w//2`. The
  extended code is doubly even (it is self-dual and its basis words have
  weight 16; MacWilliams and Sloane, *The Theory of Error-Correcting
  Codes*, ch. 16), so the OEIS terms are A₀, A₄, …, A₄₈, and `w.count(2*k)`
  prints A₄ₖ, the number of codewords of weight exactly 4k, for k = 0…12.

**Notes**

- A full enumeration, so the counts rest on nothing but the code's
  generator. Gleason's theorem (an extremal doubly-even self-dual code of
  length 48 has a unique weight enumerator) gives the same numbers.
- The list of 2²⁴ weights takes about 140 MB (the ints are small, so it
  stores pointers to cached objects); the 13 counts then take a fraction of
  a second each. All 13 terms arrive after a few seconds; the bar is all of
  them in 60 s.
