3314e0bc3788 Exhaustive search over all Costas arrays, no stored terms. Dots are coded K*x+y with K=2n (|dy|<n, so a code difference determines the displacement); one dot per column, and the nonzero-row-difference set {a-b : (a-b)%K != 0} has exactly k(k+1) elements for k+1 dots iff rows are distinct and vectors are distinct, so partial arrays are pruned exactly. Classes by Burnside: for n >= 3 no Costas array is fixed by the half-turn (columns 0,1 and n-2,n-1 would repeat a vector), hence none by quarter-turns, and the mid-row/mid-column reflections fix no permutation array; so a(n) = (C + 2S)/8 with S = number of involutions (transpose-fixed; the antitranspose fixes as many). Each completed array (k = n, the only k with k//n = 1) adds 3**[involution], i.e. 3 or 1, tested by swapping x and y in the codes (a dot in column n would repeat a row, so the search stops there); (total+7)//8 also gives a(1)=a(2)=1. Matches all 10 required terms; correct for every n, only time-limited.
