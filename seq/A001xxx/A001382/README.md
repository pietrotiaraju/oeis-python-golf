# A001382

> Weight distribution of ternary [ 24,12,9 ] quadratic residue code (also of Pless symmetry code).
> — [OEIS A001382](https://oeis.org/A001382)

Offset 0: 1, 0, 0, 4048, 61824, 242880, 198352, 24288, 48

### Python 3 — 179 bytes

```python
c=[0]
exec("c=[int(str(x*10+j*100202011222).translate('012'*19))for x in c for j in(0,1,2)];"*12)
for k in range(9):print(sum(len(str(x).replace('0',''))+(x%3>0)==3*k for x in c))
```

**How it works**

- **The code.** 23 is a prime ≡ −1 (mod 12), so 3 is a quadratic residue
  mod 23; it has order 11, so its powers are exactly the 11 residues. Over
  GF(3), x²³ − 1 therefore splits as (x − 1)·g(x)·g\*(x) with two
  irreducible factors of degree 11: g(x) = ∏(x − αʳ) over the residues r,
  and the factor for the non-residues. The cyclic code generated by either
  is the ternary quadratic-residue code [23, 12, 8] (the two are equivalent
  under i ↦ −i). Here g(x) = x¹¹ + 2x⁸ + 2x⁶ + x⁴ + x³ + 2x² + 2x + 2: it
  divides x²³ − 1 and has degree 11, which by the splitting makes it a QR
  generator. Adding the coordinate c∞ = Σcᵢ (any fixed nonzero multiple
  gives the same weights) extends it to the self-dual [24, 12, 9] code of
  the OEIS name (which notes that the Pless symmetry code of length 24 has
  the same weight distribution).
- **Words as decimal numbers.** A word of the length-23 code is written in
  decimal, one digit (0, 1 or 2) per coordinate, digit j being the
  coefficient of xʲ. So g is `100202011222`, its coefficients from x¹¹
  down to x⁰. The words g(x)·xⁱ, i = 0…11, have different degrees, so they
  are a basis of the 3¹² codewords.
- **All codewords, Horner style.** Starting from `[0]`, `exec` runs the
  step 12 times: every word x becomes 10x + j·g for j = 0, 1, 2 (multiplying
  by 10 is multiplying by x). After 12 steps the list holds every
  Σ jᵢ·g(x)·x¹¹⁻ⁱ, each codeword exactly once. 10x + j·g adds digit by
  digit without carries (each digit is at most 2 + 2·2 = 6), and
  `translate('012'*19)` reduces every digit mod 3 (the table is indexed by
  character code, and the code 48 + d of digit d is ≡ d mod 3).
- **Counting.** The weight of the length-23 word is the number of nonzero
  digits, `len(str(x).replace('0',''))` (leading zeros are simply absent).
  The extension digit c∞ = Σcᵢ is nonzero exactly when the digit sum is
  not divisible by 3, and a decimal number is ≡ its digit sum mod 3, so the
  extended weight is that count plus `(x%3>0)`. Every weight of a
  self-dual ternary code is a multiple of 3, and the OEIS terms are
  A₀, A₃, …, A₂₄; for k = 0…8 the program prints how many of the 531441
  words have extended weight exactly 3k, and stops.

**Notes**

- A full enumeration, so the counts rest on nothing but the code's
  generator. Gleason's theorem for extremal self-dual ternary codes of
  length 24 gives the same enumerator.
- The sequence is finite (9 terms); the bar is all of them in 60 s, which
  takes a few seconds.
