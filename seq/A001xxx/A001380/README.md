# A001380

> Weight distribution of binary Golay code of length 24.
> — [OEIS A001380](https://oeis.org/A001380)

Offset 0: 1, 0, 759, 2576, 759, 0, 1

### Python 3 — 108 bytes

```python
c=[0]
exec('c+=[x^5574*len(c)^1for x in c];'*12)
for k in range(7):print(sum(x.bit_count()==4*k for x in c))
```

**How it works**

- **The code.** Over GF(2), x²³ − 1 = (x + 1)·g(x)·g\*(x) with
  g(x) = x¹¹ + x⁹ + x⁷ + x⁶ + x⁵ + x + 1 and g\* its reciprocal. The cyclic
  code of length 23 generated by g is the binary Golay code [23, 12, 7] (it
  is also the quadratic-residue code of length 23); adding an overall parity
  bit gives the extended Golay code [24, 12, 8] of the OEIS name. Its
  weights are all multiples of 4, and the OEIS terms are A₀, A₄, …, A₂₄,
  the numbers of codewords of weight 0, 4, …, 24: a(k) = A₄ₖ.
- **A basis.** The words g(x)·xⁱ, i = 0…11, have different degrees, so they
  are independent and span the 2¹² = 4096 codewords. As a bit mask, g is
  2787 (bit j is the coefficient of xʲ); the program shifts it up one place
  and puts the parity bit in bit 0. g has 7 terms, an odd number, so every
  basis word gets parity bit 1: row i is 5574·2ⁱ + 1 (5574 = 2·2787). The
  parity of a sum is the sum of the parities, so XOR of rows keeps the
  parity bit right.
- **All codewords.** `c=[0]`, and `c+=[x^row for x in c]` for each of the
  12 rows doubles the list: it ends as every XOR of a subset of the rows,
  each codeword exactly once. `exec` runs that statement 12 times; before
  the i-th run (i = 0…11) the list has 2ⁱ words, so `5574*len(c)` is
  5574·2ⁱ, and `x^5574*len(c)^1` is x ^ (5574·2ⁱ) ^ 1, x XOR row i.
- **Counting.** `x.bit_count()` is the weight; for k = 0…6 the program
  prints how many of the 4096 words have weight 4k, and stops.

**Notes**

- Nothing is stored but the generator polynomial: the counts come from the
  full enumeration, so the program does not rest on the weight enumerator
  being known (it agrees with Gleason's theorem for this extremal doubly-even
  self-dual code, which pins it down from A₀ = 1 and A₄ = 0).
- The sequence is finite (7 terms); the bar is all of them in 60 s, which
  takes a few milliseconds.
