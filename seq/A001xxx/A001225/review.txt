# it computes the sequence for every n. This file changes only through pull requests.
70ed3e127f8d a(n) = min over n-node tournaments T of f(T), the largest number of arcs consistent with one linear order (OEIS formula C(n,2) - A003141(n)). f is computed exactly by the subset DP F[S] = max_v F[S-v] + |in(v) & S|. The search enumerates labelled tournaments whose identity order is optimal: every T has such a labelling (relabel along a best order), and a prefix of an optimal order is optimal for the prefix (cross arcs do not depend on inner orders), so prefixes stay in the family. Vertex k with in-set X is added only if no order beats the identity, tested exactly over every split R (vertices after k): F[~R]+F[R]+e(~R->R)+|X xor R| <= F[V]+|X|. R = V gives |X| >= k/2, so the excess fw - floor(k^2/4) never decreases along prefixes and round s (s = 0, 1, ...) visits every identity-optimal tournament of excess <= s. The first node of a new depth k, reached in round s, has excess exactly s = the minimum (round s-1 visited all of excess <= s-1 and reached no such depth), so the printed F[-1] = fw = f = a(k). No conjecture or outside theorem is used; terms match OEIS for n <= 11 and a brute force over all labelled tournaments for n <= 6.
