4c4e8f0f3df5 Brute force from the definition. Both programs count the ordered pairs (a,b) of permutations of {0..n-1} whose generated subgroup is all of S_n and halve the count: C(*g) is a breadth-first closure under right multiplication by the generators (in a finite group the products of generators already form the generated group), and C(a,b)==P compares with the set of all n! permutations. For n>=3 a single permutation generates a cyclic group, never S_n, so a=b never counts and each set {a,b} is counted twice; for n=1,2 the counts 1 and 3 halve (floor) to the right 0 and 1. py3-5.py tries all n!^2 pairs. py3.py computes the count f(a) once per conjugacy class of a (valid because conjugating a and b by the same permutation preserves generation), keyed by sum_i n^(length of the cycle through i), which determines the cycle type (base-n digits; the page proves injectivity). No theorem beyond that is used, so both are correct for every n; only speed limits them (a(6) at 3.8 ref s, a(5) at 1.5 ref s).
