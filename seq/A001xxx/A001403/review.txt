9547fbaa6ef2 Exhaustive search with an exact isomorphism test. Every (n_3) configuration has the three lines through a point meeting only there, so n >= 7 (a(1..6) = 0, the n>6 guard) and it can be relabelled to have lines {0,1,2},{0,3,4},{0,5,6} through point 0; the search starts there and adds sorted triples in increasing order, each starting at the smallest point still on fewer than 3 lines (every configuration is reached: its sorted line list is such a path), each meeting old lines in at most one point and using only points on fewer than 3 lines; n lines then give exactly 3 lines per point. Canonical form: min over relabellings o = (p, the 6 points collinear with p in any order, the rest in any order) of an injective integer code (sum of 2^mask over lines); the order set is defined by the structure, so it is an isomorphism invariant, and it is the code of a relabelling, so equal codes mean isomorphic. len(S) = number of classes.
