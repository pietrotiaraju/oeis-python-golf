# it computes the sequence for every n. This file changes only through pull requests.
c2313160ef5d Wire of n unit segments bent by 0 or +-90 degrees at each mark, may cross itself but never reuses a lattice edge, counted up to rotation, reflection and reading from the other end (OEIS comments: undirected trails up to symmetry); a brute force over turn words reproduces the data. The program enumerates turn words as balanced-ternary N with n-1 digits; mirror is -N and reversal is -r (r = digit reversal), so each orbit {N,-N,r,-r} is counted once at its largest member, N >= |r|. Trail test: the n doubled edge midpoints 2p+d are distinct. Exhaustive over all words, complex parts are integers <= 2n+1, so correct for every n.
