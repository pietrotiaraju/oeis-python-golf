ab381fdca3ec Definition: a(n) is the number of polygons with 2n edges on the simple cubic lattice up to translation, a(0)=1. For n>=2 each such polygon is traced by exactly 4n closed self-avoiding walks from the origin (2n choices of the vertex placed at the origin times 2 directions; all are different step sequences because a finite polygon has no nonzero translation symmetry), so a(n)=c(n)/(4n) with c(n)=A001413(n) the number of walks p0=0,p1,...,p2n=0 with p1..p2n distinct; for n=1, c=0. The program computes c(n) by the exhaustive search of A001413: the visited set starts as the placeholder {.5} so the origin is not marked, steps go to unvisited neighbours p+-1, p+-B, p+-B^2, and after 2n steps the walk scores 1 iff it is at the origin, except that p==0<B^2 (B XOR 2 is 0 only for B=2) rejects the six out-and-back walks of n=1. Codes x+yB+zB^2 with B=2n are exact: a nonzero vector with code 0 has |x|+|y|+|z|>=2n+1, more than any two points of a 2n-step walk are apart. It prints c//(2B)=c/(4n); for n=0 the root is a finished walk (count 1) and the divisor B*2or 1 is 1. Exact integer arithmetic, no truncation: correct for every n (only time-limited).
