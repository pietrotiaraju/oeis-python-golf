5b12523c271e Definition: a(n) is the number of n-step self-avoiding walks on the kagome lattice from a fixed site (the lattice is vertex-transitive). The kagome lattice is taken as the triangular lattice in skew coordinates (i,j) (steps +-(1,0), +-(0,1), +-(1,-1)) minus the coset {i, j both odd} of 2Z^2; every remaining site keeps exactly its four kagome neighbours. Points are coded i+jB with B=2^(n+1) and the walk starts at (n,0), so i stays in [0,2n], inside [0,B): the code is one-to-one on all reachable points (S is an exact visited set), and bits 0 and n+1 of the code are the parities of i and j, so ~w&B+1 is 0 exactly at deleted points. f is an exhaustive depth-first search over unvisited kept neighbours, scoring 1 when the walk has n+1 points; exact integers, no truncation, so the output is a(n) for every n (only time-limited). It matches the corrected data (a(12)=224640, a(13)=589024). 16 terms fit in a table shorter than the program, hence the review.
