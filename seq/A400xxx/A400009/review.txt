8775760d5a34 The program is the plain Sprague-Grundy search of the game in the name. A position is the increasing tuple of numbers not yet crossed out; the board for n is (2,...,n), built by appending len(s)+2. A move x keeps exactly the y with y mod x != 0 (filter(x.__rmod__,s)), i.e. crosses out x and its multiples, and every move removes x, so the game is finite. Normal play (last move wins) makes the value the Grundy number: mex of the options, 0 for the empty board. A position with k numbers has k options, so the mex lies in range(k+1). Equal sets give equal increasing tuples and the value of a position does not depend on n, so the shared cache only saves work. Nothing about the terms is assumed, and the output matches all 31 draft terms it reaches.
