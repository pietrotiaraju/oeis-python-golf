# Programs read and approved: the first 12 hex digits of the SHA-256 of the program, then why
# it computes the sequence for every n. This file changes only through pull requests.
8af8a5b59159 a(n) are the record-setting primes p == 1 (mod 4) for the class number h(p) of the real field Q(sqrt p). The program computes h(k) exactly for every prime k == 1 (mod 4): it lists the reduced indefinite forms of discriminant k as pairs (A = 2|a|, b) with b odd in [1, floor(sqrt k)], floor(sqrt k) - b < A <= floor(sqrt k) + b, A even and 2A | k - b^2 (sqrt k is irrational, so the floors give the exact reduction inequalities), then walks Gauss's reduction cycles (A' = (k - b^2)/A, b' = s - (s + b) mod A', the largest b' <= s with b' == -b mod A') and counts the cycles of the sign-forgetting walk, which are the wide ideal classes (equal to the narrow ones here, since N(eps) = -1 for prime p == 1 mod 4, though the count does not need this). Composite k get an empty form set via trial division and h = 0. Records are printed when h exceeds the running maximum, so the output is the sequence for every n; all integer arithmetic.
