d7d17f8f4ba9 a(n) is where A185091 (the smallest positive noncomposite q with N = 2p + q, p positive noncomposite) sets its n-th record, N odd. The program runs m over the odd numbers 3, 5, 7, ... and keeps L = [1, odd primes up to m] in increasing order and T = {2p : p = 1, 2 or an odd prime up to m}. Primality of m is exact trial division: with b the bit length of m, L[1:2^floor(b/2)] holds the 2^floor(b/2) - 1 smallest odd primes, and that is at least the number of odd numbers from 3 to sqrt(m) < 2^(b/2), so every odd prime up to sqrt(m) is tried (m is odd, so 2 is not needed). For odd N = m, q must be odd and m - q = 2p with 1 <= p <= m, so the first q in L with m - q in T is exactly A185091 at m; the program prints m when that q beats the record r (r starts at 0, so N = 3 with q = 1 is a(1)). No conjecture is used: an N without a representation would give next(...,0) = 0 and set no record. Integer arithmetic only, so every term printed is a(n) for every n. Its 20 required terms are checked against the b-file (49 terms, up to about 8.6e12).
