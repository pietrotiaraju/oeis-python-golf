779111e714db Counts positive (monotone) threshold functions of n inputs: each N-class (complementing inputs) of threshold functions holds exactly one (threshold functions are unate; two positive members would differ only on irrelevant inputs). By the Muroga-Toda-Takasu bound, integer weights |w_i| <= floor((n+1)^((n+1)/2)/2^n) suffice, and for a positive function the negative weights can be raised to 0, so the positive threshold functions are exactly [w.x > t] with 0 <= w_i <= B and t in {-1} plus the sums. The program enumerates sorted weight vectors (the NP-class representatives of A000617), applies all n! input permutations (index maps built by the same doubling with weights 1,2,...,2^(n-1) in every order) and counts distinct truth tables. B is computed exactly with isqrt; correct for every n given that theorem. Bar is n = 0..6 (n = 7 needs 15 million sorted vectors), hence the review.
