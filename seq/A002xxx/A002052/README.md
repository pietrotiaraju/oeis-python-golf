# A002052

> Prime determinants of forms with class number 2.
> — [OEIS A002052](https://oeis.org/A002052)

Offset 1: 3, 7, 11, 19, 23, 31, 43, 47, 59, 67, 71, 83, 103, 107, 127, 131, 139, …

### Python 3 — 168 bytes

```python
p=3;r=m=1
while 1:
 r+=(r+1)**2<p;S=[1]
 for d in S:m=r-(r+m)%d;S+=[e:=(p-m*m)//d]*(e>1)
 all((x*x-p)%q or q in S for q in range(r+1)for x in range(q))and print(p);p+=4
```

**How it works**

- **The definition.** Gauss's forms ax² + 2bxy + cy² of determinant
  b² − ac = p are the forms of discriminant 4p, and their class number
  counts the primitive ones up to proper equivalence: h⁺(4p). Counting
  the cycles of reduced forms for every prime below 12000 gives exactly
  the data (counting the imprimitive forms 2·(form of discriminant p)
  as well would add every p ≡ 1 (mod 4)). The entry's PARI program says
  the same thing in other words: p ≡ 3 (mod 4) and the class number of
  Z[√p] is 1.
- **Only p ≡ 3 (mod 4).** By Gauss's genus theory the number of genera,
  which is also the number of classes of order at most 2, is 1 for
  discriminant 8 and for 4p with p ≡ 1 (mod 4), so there h⁺ is odd, never
  2. For p ≡ 3 (mod 4), x² − py² = −1 is impossible (−1 is not a square
  mod p), so no unit has norm −1 and h⁺ = 2h, where h is the class number
  of Z[√p], the ring of integers of Q(√p). So the terms are the primes
  p ≡ 3 (mod 4) with h = 1, and p runs through 3, 7, 11, … in steps of 4.
- **Minkowski.** Every ideal class contains an ideal of norm at most
  √(4p)/2 = √p, so the class group is generated by the prime ideals of
  norm q < √p. For an inert q that ideal is (q); otherwise q has a prime
  ideal of norm q, which is principal (and then so is its conjugate)
  exactly when x² − py² = ±q has a solution.
- **Lagrange.** If |x² − py²| < √p with x, y > 0 coprime, x/y is a
  convergent of √p and x² − py² is ± one of the denominators dₖ of the
  continued-fraction algorithm (and every dₖ is such a value). The
  `for` line runs that algorithm, m ← r − (r + m) mod d (that is,
  aₖdₖ − mₖ with aₖ = ⌊(r + mₖ)/dₖ⌋) and d ← (p − m²)/d, with r = ⌊√p⌋.
  It loops over S while appending to it: S starts as [1], and from d = 1
  the first step gives m = r whatever m was, then d = p − r² ≥ 2; every
  later dₖ is appended until the period closes with d = 1, which is not
  appended again. So S holds the dₖ of one period.
- **The test.** p is printed when every q from 1 to r with a root x of
  x² ≡ p (mod q) is in S (q = 0 has no x to try, and 1 is always in S). For a prime q this is the criterion above, so
  a prime p passes exactly when h = 1. A composite q never rejects such a
  p: a root gives the primitive ideal [q, x + √p] of norm q, principal
  when h = 1 and generated by an element with coprime coefficients and
  norm ±q, so q is in S by Lagrange.
- **No primality test is needed.** If s² | p with s > 1, a prime q | s
  has the root x = 0 but cannot be in S (q | x would give q² | q). If p
  is squarefree with two or more prime factors, Z[√p] is the ring of
  integers of discriminant 4p with at least three prime factors, so
  genus theory gives at least 4 genera, h⁺ ≥ 4 and h ≥ 2: some prime
  ideal of norm q < √p is not principal, no element has norm ±q, and q,
  which has a root, is not in S. So composite p always fail the test.
- r = ⌊√p⌋ is kept by `r+=(r+1)**2<p`: p grows by 4, is never a square,
  and √(p + 4) − √p < 1.

**Notes**

- Exact integer arithmetic throughout; the program rests on the theorems
  named above (Gauss's genus theory, Minkowski's bound, Lagrange's
  theorem on convergents), not on any conjecture.
- The test costs about p/2 steps per candidate. Testing only primes q
  with Euler's criterion, `p%q*(q in S or pow(p,q//2,q)>1or
  0in(q%j for j in range(2,q)))` over q from 2, is 27 bytes longer and
  does the whole b-file in about 10 s here.
- The b-file has 10000 terms, up to 291619. The bar is 4000 terms
  (up to 104723) in 60 s; they take about 23 s here.
