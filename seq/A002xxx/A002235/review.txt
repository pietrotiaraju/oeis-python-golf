620397ad53d3 Definition: m with 3*2^m-1 prime. The program runs the Lucas-Lehmer-Riesel test with Rodseth's parameter (Riesel 1969, Rodseth 1994): P = k^2+2, where k is moved on until (k^2+4)^((N-1)/2) mod N is not 0 or 1, so for prime N Euler's criterion gives (P-2|N)=1, (P+2|N)=-1; it prints n iff V_3(V_{2^(n-1)}(P)) = V_{(N+1)/2}(P) = -2 mod N. The page proves it for every n >= 2 (2^n > 3): the k search always ends (a non-residue k^2+4 exists mod each prime factor and (N-1)/2 is odd); N prime gives alpha^(N+1) = -1 by Frobenius, so it prints; printing forces every prime factor to be +-1 mod 2^n, impossible for composite N < 4^n-1. n = 0 (N = 2) is printed directly and n = 1 (N = 5) by the prime half of the proof.
