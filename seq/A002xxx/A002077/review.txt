ce67f8939448 Counts positive self-dual threshold functions of exactly n inputs (one per N-class). Via self-dualization g = x_n f + ~x_n f^d, these correspond to positive threshold functions f of n-1 inputs with f^d <= f (f(x) or f(~x) for all x), f != f^d (g depends on x_n) and f depending on all n-1 inputs (g depends on x_i iff f does); the pair-sum test {f(x)+f(~x)} - {1} == {2} covers the first two, and with sorted weights f depends on all inputs iff it depends on the lightest one (f[::2]!=f[1::2]), all proved on the page. f is enumerated with the Muroga-Toda-Takasu bound on sorted nonnegative integer weights and all cuts, then all input permutations are applied and distinct truth tables counted. Exact isqrt bound; correct for every n given that theorem. Bar n = 1..7, hence the review.
