5ae9e3a13911 Counts positive (monotone) threshold functions of n inputs that depend on all n inputs: each N-class of threshold functions holds exactly one positive member (unateness). Muroga-Toda-Takasu: integer weights |w_i| <= floor((n+1)^((n+1)/2)/2^n) suffice, negative weights of a positive function can be raised to 0, so the program enumerates sorted weight vectors 0 <= w_1 <= ... <= w_n <= B with all cuts, keeps those depending on the lightest input (with sorted weights the lightest input is the weakest: if f depends on it, it depends on every input, proved on the page; f[::2]!=f[1::2] tests bit 0), applies all n! input permutations and counts distinct truth tables. Exact isqrt bound; correct for every n given that theorem. Bar n = 0..6, hence the review.
