5c20d7606df0 Definition: k with k*2^k-1 prime (Woodall). It runs the Lucas-Lehmer-Riesel test with Rodseth's parameter (Riesel 1969, Rodseth 1994): P = k^2+2, where k is moved on until (k^2+4)^((N-1)/2) mod N is not 0 or 1, so for prime N Euler's criterion gives (P-2|N)=1, (P+2|N)=-1. With N = n*2^n-1 = h*2^e-1 (h odd part of n, h < 2^e) it prints n iff V_{(N+1)/4}(P) = 0 mod N, computed as V_{2n}(k,-1) by the linear recurrence and n-2 squarings. The page proves it for every n with n >= 2 (h < 2^e always): the k search always ends (a non-residue k^2+4 exists mod each prime factor and (N-1)/2 is odd); N prime gives alpha^(N+1) = -1 by Frobenius (alpha a root of x^2-kx-1), so it prints; printing forces every prime factor to be +-1 mod 2^e, impossible for composite N < 4^e-1. n = 1 gives N = 1 and is skipped.
