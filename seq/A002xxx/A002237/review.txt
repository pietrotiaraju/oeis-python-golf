c10e383f3b7b Definition: k with 15*2^k-1 prime. It runs the Lucas-Lehmer-Riesel test with Rodseth's parameter (Riesel 1969, Rodseth 1994): P = k^2+2, where k is moved on until (k^2+4)^((N-1)/2) mod N is not 0 or 1, so for prime N Euler's criterion gives (P-2|N)=1, (P+2|N)=-1. It prints n iff V_{(N+1)/2}(P) = V_{N+1}(k,-1) = -2 mod N (30 linear steps, then n-1 squarings). The page proves it for every n with 2^n > h: the k search always ends (a non-residue k^2+4 exists mod each prime factor and (N-1)/2 is odd); N prime gives alpha^(N+1) = -1 by Frobenius (alpha a root of x^2-kx-1), so it prints; printing forces every prime factor to be +-1 mod 2^n, impossible for composite N < 4^n-1. Small n: n = 1, 2 (N = 29, 59) are printed by the prime half; n = 3 (N = 119) was run and is not printed.
