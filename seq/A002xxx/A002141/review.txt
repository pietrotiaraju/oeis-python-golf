The program walks the odd primes by Wilson's theorem with the squared factorial, keeps the search monotone (each condition set contains the previous one, so the search resumes at the last N, in steps of 24 since N == 7 mod 24), tests each condition by Euler's criterion, and counts reduced forms of discriminant -N exactly; N is squarefree by minimality (a square factor prime to all q could be removed), so -N is fundamental and all forms are primitive. The count handles the boundary cases a = c and |b| = a that composite N allows, so it is correct for every n.
