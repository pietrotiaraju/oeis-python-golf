1347a7b685c1 a(n) is the n-th record value of A185091 (the smallest positive noncomposite q with N = 2p + q, p positive noncomposite), N odd. Same search as A002091: m runs over the odd numbers 3, 5, 7, ..., L = [1, odd primes up to m] in increasing order, T = {2p : p = 1, 2 or an odd prime up to m}. Primality of m is exact trial division: with b the bit length of m, L[1:2^floor(b/2)] holds the 2^floor(b/2) - 1 smallest odd primes, at least the number of odd numbers from 3 to sqrt(m) < 2^(b/2), so every odd prime up to sqrt(m) is tried. For odd N = m, q must be odd and m - q = 2p with 1 <= p <= m, so the first q in L with m - q in T is exactly A185091 at m; the program prints q when it beats the record so far (r starts at 0, so a(1) = 1 at N = 3). No conjecture is used: an N without a representation would give 0 and set no record. Integer arithmetic only, so it is correct for every n. Its 20 required terms are checked against the b-file (49 terms).
